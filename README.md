# flutter_button_navigation

Practical Assignment material buttons and navigation in flutter

A simple Flutter app with a Button Gallery and multiple screens, using Navigator push, pop, pushReplacement and named routes.

###Features
- Login, Button Gallery, Profile, Details, Settings and Add screens

- Elevated, Filled, Filled Tonal, Outlined, Text, Icon, Floating Action and custom buttons

- Navigator.push(), Navigator.pop(), Navigator.pushReplacement()

- Named routes with Navigator.pushNamed()
